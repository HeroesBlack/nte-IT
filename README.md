# NTE IT

Traduzione italiana per Neverness to Everness.

## Come usare

1. Scarica `NTEITALauncherSetup.exe` dalle [releases](https://github.com/HeroesBlack/nte-IT/releases/latest).
2. Installa e avvia il launcher (richiede privilegi di amministratore).
3. Se il gioco non viene rilevato automaticamente, clicca `SELEZIONA CARTELLA GIOCO` e scegli la cartella che contiene `NTEGlobalLauncher.exe` (es. `C:\Program Files\Neverness to Everness`).
4. Clicca `INSTALLA TRADUZIONE` per installare/aggiornare la patch italiana.
5. Clicca `GIOCA` per avviare il gioco.

## Note

- La traduzione italiana e distribuita tramite questo repository.
- Le impostazioni del launcher e lo stato della traduzione vengono salvati automaticamente.
- Per la traduzione italiana usa **sempre** questo launcher.
- Per aggiornare il gioco usa il launcher ufficiale di Neverness to Everness.
